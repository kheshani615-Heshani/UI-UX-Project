## 📌Project Overview


SREA is a UI/UX design project for a Student Examination Results System. It aims to provide a simple and user-friendly interface for managing students, teachers, subjects, marks, and examination results.


## 📐 Tools Used

- Figma
- UI/UX Design
- Wireframing and Prototyping

## 🎨 Figma Design

[View My Figma Project](https://www.figma.com/design/zIQSzBNzCwdyvuuAD7onVd/Student-Examination-Result-System-Design-System?node-id=0-1&t=UPpYNfzqE0FzfGVP-1)


## 🔍Main Features

- Login and account creation
- Student and teacher management
- Subject and examination management
- Marks entry and grade assignment
- Examination results dashboard
- Profile and settings
